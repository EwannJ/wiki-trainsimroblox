Rôles

Sur TSR, on distingue 3 rôles accessibles dans la carrière de tout joueur.

Joueurs :

🧳 Voyageurs

Description :

  • Rôle de base obtenable par tous les joueurs.

Condition d'obtention :

  • Avoir rejoint le groupe du jeu.

Gain :

  • Ce rôle vous permet de débloquer la BB60000.

🚂 Agent De Conduite (ADC)

Description :

  • Rôle certifiant que vous connaissez la signalisation française présente dans TSR et que vous pouvez conduire en toute sécurité.

Condition d'obtention :

  • Avoir rejoint le groupe du jeu
  • Réussir le test ADC sur le Centre d'Application à l'aide du document ADC présent dans Formations.

Gain :

  • Ce rôle vous permet de débloquer la BB27000 et la possibilité de faire des Alertes Radios.

🦺 Agent De Régulation (ADR)

Description :

  • Former les futurs Agents de Régulation et veiller à la bonne conduite en jeu comme en régulation, c'est la mission principale des agents référents. Ils agissent parfois en coulisses, mais leur travail est essentiel pour garantir un accompagnement de qualité et un environnement agréable pour tous.

Condition d'obtention :

  • Réussir le test ADR sur le Centre d'Application à l'aide du document ADC présent dans Formations.
  • Réussir le test pratique via Discord à l'aide du document ADR présent dans Formations.

Gain :

  • Ce rôle vous permet de gérer la régulation des trains en jeu.

Administration :

🏛️ Responsable Réseau (RR)

Description :

  • Encadrer les joueurs et faire respecter le règlement, c'est la mission principale des staffs sur TSR. Ils sont peu visibles, mais pourtant font un travail énorme pour vous permettre de jouer sans soucis.

Condition d'obtention :

  • Parler français.
  • Avoir de bonnes connaissances dans le RFN français.
  • Ouvrir un ticket sur notre serveur Discord pour faire sa candidature.

🛡️ Staff

Description :

  • Encadrer les joueurs et faire respecter le règlement, c'est la mission principale des staffs sur TSR. Ils sont peu visibles, mais pourtant font un travail énorme pour vous permettre de jouer sans soucis.

Condition d'obtention :

  • Parler français.
  • Réussir les 3 tests théoriques Staff sur le Centre d'Application.
    Nota : Réussir les tests mentionnés ci-dessus ne signifie pas que vous passerez à l'étape suivante. En effet, l'équipe exécutive doit être en recherche de staff pour regarder les candidatures.
  • Réussir les étapes suivantes qui vous seront communiquées si votre candidature a été retenue.

💎 Manager

Description :

  • Bras droits du Créateur, ils assurent la gestion des staffs et la cohésion entre les différentes équipes de TSR.

Condition d'obtention :

  • Être dans l'équipe administrative de TSR.

🔨 Développeur

Description :

  • Ils aident le Créateur à développer le jeu.

Condition d'obtention :

  • Savoir développer en LuaU.
  • Ouvrir un ticket sur notre serveur Discord pour faire sa candidature.

✨ Créateur

Description :

  • Créateur du jeu Train Simulator Roblox. Il s'agit de Julien.

Condition d'obtention :

  • Impossible.
