Accueil / Aide conduite

Console

L'attelage, la freecam et le 2e pantographe ne sont pas accessibles sur console.

Toutes les touches
  • X Allumer/éteindre le train

Procédure de démarrage
  • X Allumer la batterie (3 sec sur la NAT)
  • ➕↑ Inverseur avant

Procédure de changement de tension

Avant le panneau "baissez pantographe" :

  • X Eteindre le train

Après le franchissement du panneau "Rev" :

  • X Allumer le train
